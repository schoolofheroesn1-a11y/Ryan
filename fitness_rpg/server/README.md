# Сервер мультиплеера (api.php)

Один PHP-файл для обычного хостинга (PHP 7.1+, MySQL). Таблицы `mp_*` создаются сами при первом
запросе, 30 ботов лестницы «Бросить вызов» — при первой регистрации.

| Файл | Что это |
|---|---|
| `api.php` | аккаунты, рейтинг, вызовы, дуэли, коды — кладётся рядом с `index.html` |
| `codes.php` | хэши кодов активации платного контента (самих кодов в репозитории нет) |
| `lb_config.example.php` | образец настроек базы; на сервере — `lb_config.php` (в git не хранится) |

- **Аккаунт:** логин и пароль (на сервере — хэш `password_hash`), вход на любом устройстве. Рекорд
  только растёт; вместе с ним сохраняются характеристики и снаряжение героя.
- **Рейтинг:** по побеждённым боссам, затем уровню и раунду (только игроки).
- **Бросить вызов:** лестница игроков и ботов. Вызов — до 3 мест выше или ниже, 10 попыток в день
  (сброс в полночь по Москве). Против вас бьётся бот с характеристиками соперника. Победа над тем,
  кто выше, — обмен местами. Бой засчитывается не раньше чем через 8 секунд.
- **Дуэль:** комната с кодом из 4 символов; события боя идут через сервер ~3 раза в секунду.
  Попал ли удар, решает телефон защищающегося.
- **Коды:** `python tools/make_codes.py <товар> <сколько>` — новые коды; строки с хэшами добавить в
  `codes.php`. Один код работает для любого числа игроков; со входом в аккаунт покупка сохраняется в нём.
- **Защита:** лимиты запросов с одного адреса (IP хранится хэшем), очистка имён, `.htaccess` закрывает
  `lb_config.php` и `codes.php`. Результаты боёв считает телефон игрока, поэтому полной защиты от
  подделки нет — как и в большинстве браузерных игр без своего игрового сервера.

Проверка на своём компьютере (PHP с pdo_sqlite): положить `api.php`, `codes.php` и `lb_config.php` с
`'dsn' => 'sqlite:/tmp/mp.sqlite'` рядом с папкой `web/` и запустить `php -S 127.0.0.1:8799` в ней.

## Оплата через Robokassa

Платные облики, гриф и поддержка проекта на сайте оплачиваются через Robokassa. Цены в рублях — в `api.php`
(`PAY_ITEMS`): сервер сам подписывает счёт, подделать сумму из игры нельзя. Покупка выдаётся в аккаунт игрока
(для покупки нужен вход в «Мультиплеере»), когда Robokassa присылает уведомление об оплате.

1. На хостинге скопируйте `robokassa_config.example.php` как `robokassa_config.php` (рядом с `api.php`) и впишите
   пароли из кабинета Robokassa: «Мои магазины» → магазин → «Технические настройки». Сначала — тестовые пароли
   и `'test' => true`. Файл с паролями закрыт `.htaccess`, в git его не кладите.
2. В «Технических настройках» магазина:
   - **Result URL:** `https://ash-a-iron.com/api.php?action=robokassa_result`, метод **POST**;
   - **Success URL:** `https://ash-a-iron.com/pay_success.html`, метод **GET** (Robokassa не принимает GET-адреса с параметрами);
   - **Fail URL:** `https://ash-a-iron.com/pay_fail.html`, метод **GET**;
   - алгоритм хеша — тот же, что в `robokassa_config.php` (`md5`).
3. Тест: купите облик в игре — откроется страница Robokassa с пометкой теста, оплата не списывается;
   после неё облик появится в игре.
4. Боевой режим: впишите боевые Пароль №1 и №2 и поставьте `'test' => false` — только когда магазин прошёл
   проверку Robokassa и тестовая оплата работает.

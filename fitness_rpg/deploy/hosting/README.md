# Ash & Iron на своём домене (хостинг sweb.ru)

Архив `dist/ash-a-iron-hosting.zip` собирается так:
`sh tools/build_web_release.sh`, затем файлы из `dist/ash-and-iron-web/` (без README_DEPLOY.md,
supabase.sql, .nojekyll) плюс `deploy/hosting/.htaccess` — все в корне архива, без вложенной папки.

## Шаги в панели sweb (cp.sweb.ru)
1. **Привязать домен к сайту.** Раздел «Сайты»: создать сайт для `ash-a-iron.com` или привязать домен
   к существующему. Запомнить папку сайта (обычно `public_html` внутри папки сайта).
2. **DNS.** Если домен и хостинг в одном аккаунте sweb, записи обычно ставятся сами. Иначе в «Домены» →
   DNS: A-запись `@` и `www` на IP хостинга (он указан в панели). Обновление — до 24 часов.
3. **Загрузить игру.** «Файловый менеджер» → папка сайта → удалить заглушку (index.html/index.php
   хостинга) → «Загрузить» `ash-a-iron-hosting.zip` → правой кнопкой «Распаковать» → удалить zip.
   В папке должны лежать `index.html`, `game.js`, `.htaccess` и др. (без подпапки).
4. **HTTPS (обязательно — без него не работает камера).** Раздел «SSL-сертификаты» → бесплатный
   Let's Encrypt для `ash-a-iron.com` и `www.ash-a-iron.com`.
5. Открыть https://ash-a-iron.com и проверить: картинки, кнопки, камера, звук.

## Если что-то не так
- «Слишком много переадресаций» — значит, в .htaccess осталось правило перевода на https; в текущем .htaccess его нет, HTTPS включается в панели.
- Файлы .wasm (13 МБ) файловый менеджер может не принять — их можно не загружать: игра возьмёт их с CDN jsdelivr. Либо загрузить по FTP.
- Ошибка 500 — удалить `.htaccess` целиком и сообщить: игра откроется, но нужны типы файлов.
- Онлайн-рейтинг: если ключи Supabase были вписаны в `config.js` на GitHub, скопируйте их в
  `config.js` на хостинге.
- Обновление игры: загрузить новый архив поверх (заменить файлы). Старый кэш игроков обновится сам.

## Онлайн-рейтинг на своём хостинге
1. Панель sweb → «MySQL» (базы данных) → создать базу. Записать имя базы, пользователя и пароль.
2. В папке сайта: скопировать `lb_config.example.php` → `lb_config.php`, вписать эти данные, сохранить.
3. Проверка: открыть https://ash-a-iron.com/leaderboard.php — должно быть `{"rows":[],"rank":null}`.
   `{"error":"not configured"}` — нет lb_config.php; `{"error":"database unavailable"}` — неверные данные базы.
4. В игре: «Рейтинг» — результат появится в таблице.
Подробности и проверка на своём компьютере — `server/README.md`.

# Ash & Iron — тестовая публикация через GitHub Pages

В этом архиве готовый сайт игры. После публикации на GitHub Pages игра откроется на любом
телефоне по ссылке `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/` и будет распознавать
отжимания, приседания и «звёздочку» фронтальной камерой. Камера в браузере работает только
по HTTPS, а GitHub Pages его даёт. Распознавание позы (MediaPipe) лежит внутри архива,
в папке `vendor/`, поэтому от сторонних сайтов игра не зависит.

## 1. Залить файлы (5 минут, без программ)

1. На github.com нажмите **New repository**. Имя, например, `ash-and-iron`, видимость **Public**
   (GitHub Pages бесплатно работает с публичными репозиториями). Создайте репозиторий.
2. Распакуйте архив. На странице репозитория нажмите **uploading an existing file**
   (или **Add file → Upload files**).
3. Перетащите в окно **всё содержимое** распакованной папки `ash-and-iron-web`:
   `index.html`, `style.css`, `manifest.webmanifest`, `sw.js`, `.nojekyll`
   и папки `js`, `assets`, `fonts`, `vendor`. Файлы должны лежать в корне репозитория,
   а не внутри папки `ash-and-iron-web`.
   - На Mac файл `.nojekyll` скрыт: в Finder нажмите `Cmd + Shift + .`, чтобы его увидеть.
   - Самые крупные файлы (`vendor/.../*.wasm`) весят около 13 МБ, лимит GitHub — 25 МБ на файл.
4. Нажмите **Commit changes**.

## 2. Включить сайт

**Settings → Pages → Build and deployment → Source: Deploy from a branch**,
ветка **main**, папка **/ (root)** → **Save**. Через 1–2 минуты сверху появится ссылка на сайт.

## 3. Проверить на телефоне

- **iPhone:** откройте ссылку в **Safari**, нажмите «С КАМЕРОЙ» и разрешите доступ к камере.
  Чтобы игра запускалась как приложение: **Поделиться → На экран «Домой»**.
- **Android:** откройте ссылку в **Chrome** → «С КАМЕРОЙ» → разрешить. Меню ⋮ → **Установить приложение**.
- Поставьте телефон на пол у стены, отойдите на 2–3 м. В меню «Камера и советы» видно,
  как игра видит вашу позу.

Что проверить:
- **Упражнения:** отжимание бьёт, присед (или нижняя точка отжимания) уворачивает, «звёздочка» лечит.
- **Лавка образов:** покупка в тестовом режиме бесплатна. Обликом меча, молнией и короной победы
  можно пользоваться сразу.
- **Рейтинг:** без сервера показывает ваш результат (см. пункт 4).
- **Без интернета:** включите авиарежим и перезапустите игру — она работает,
  а результат для рейтинга ждёт сети.

## 4. Рейтинг для всех игроков (необязательно, бесплатно)

Чтобы игроки видели общую таблицу, нужен сервер. Подходит бесплатный Supabase:

1. Зарегистрируйтесь на supabase.com → **New project** (любое имя, регион поближе, запишите пароль).
2. **SQL Editor → New query**, вставьте содержимое файла `supabase.sql` из архива → **Run**.
3. **Project Settings → API**: скопируйте **Project URL** и ключ **anon public**.
   Ключ `service_role` никуда не вставляйте: он секретный.
4. В репозитории откройте `js/config.js` → значок карандаша и впишите значения:
   ```js
   url: "https://xxxxxxxx.supabase.co",
   anonKey: "eyJhbGciOi...",
   ```
   **Commit changes**. Через минуту сайт обновится, и рейтинг станет общим.

## Обновление игры

Загрузите новые файлы поверх старых. Игра кэширует себя для работы без сети, поэтому
на телефоне новая версия появится после второго открытия.

## Если что-то не работает

- **«нет доступа к камере»**: на iPhone откройте Настройки → Safari → Камера → «Разрешить»,
  на Android — разрешения сайта в Chrome.
- **«модель не загрузилась»**: проверьте, что папка `vendor` загружена целиком
  (`vendor/pose_landmarker_lite.task` и `vendor/tasks-vision/...`).
- **Белый экран**: откройте ссылку именно с `/` на конце, например
  `https://login.github.io/ash-and-iron/`.

Следующий шаг — сборка для App Store (StoreKit, иконки, описание). Его готовим после того,
как вы проверите эту версию.
